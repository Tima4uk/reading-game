# 🎮 Словознайка / Słowotwórca / WordQuest

Развивающая интерактивная веб-игра для детей, помогающая учиться читать на русском 🇷🇺, польском 🇵🇱 и английском 🇬🇧 языках.

🌐 Играть онлайн: https://tima4uk.github.io/reading-game/

---

## 🕹️ Режимы игры

1. 🔍 Сетка слов (Word Search / Wykreślanka)
2. 🧩 Собери слово (Word Builder / Ułóż słowo)
3. 🧠 Умные слова (Word Logic / Mądre słowa)
4. 🔤 Азбука (Alphabet / Alfabet)

## 🚀 Локальный запуск

node server.js
